# Resident Alien — resident-alien.com

Credit for people who just got here. A starter U.S. credit line on day one for international students and newly arrived
professionals, then a coached path toward premium-card eligibility. This repository is the marketing site, the explainable
readiness-engine demo, and the community safety center.

Plan and positioning: [`docs/website-plan.md`](docs/website-plan.md). Original brief: [`docs/perplexity-brief.md`](docs/perplexity-brief.md).

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint
```

Node 20+ (built on 22). Next.js 16, React 19, Tailwind v4, TypeScript.

## Storage modes

`src/lib/storage.ts` picks a mode from the environment:

- **live** — `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` set. Run [`supabase/schema.sql`](supabase/schema.sql) once. Keys are used server-side only.
- **local** — `next dev` without Supabase. Writes to `.data/*.json` (git-ignored) so the forms work on a laptop.
- **demo** — production without Supabase. The safety map serves seeded, clearly labeled demo reports from memory; the waitlist API answers 503 with a mailto fallback instead of silently dropping signups.

Copy `.env.example` to `.env.local`.

## Credit Alien (iMessage coach)

The hero's "Chat with Credit Alien" button opens Messages to our Sendblue line. Behind it is a long-horizon coaching
agent: onboarding with explicit consent, a versioned plan with one action a week, a daily internal monitor, a weekly
check-in, and memory that survives the thread. Design, data model, setup, and testing: [`docs/credit-alien-agent.md`](docs/credit-alien-agent.md).

Env: `ANTHROPIC_API_KEY` (or `ANTHROPIC_KEY`), `SENDBLUE_API_KEY`, `SENDBLUE_SECRET`, `SENDBLUE_NUMBER` (shows the
button), `SENDBLUE_WEBHOOK_SECRET`, `CRON_SECRET`. `SENDBLUE_DRY_RUN=1` logs instead of sending.
`npm test` runs the coach's unit tests.

## Safety center rules

Built for awareness, not intervention. Reports carry a category, a note, and a location rounded to ~100 m. Notes that look
like plates, phone numbers, emails, links, or handles are rejected server-side. Reports expire after four hours. There are no
accounts; a daily-salted hash of the connection address exists only for rate limiting (3 reports/hour, 5 signups/hour).

Map tiles come from CARTO's dark basemap (free tier, attribution required). For real traffic switch to a paid CARTO plan,
MapTiler, or self-hosted OpenFreeMap tiles in `src/components/safety/safety-map.tsx`.

MapLibre spawns a module web worker from a URL relative to its own bundle, which the app bundler doesn't preserve, so the
worker would load the page HTML and die (no reports would ever render). `scripts/copy-maplibre-worker.mjs` runs before
`dev` and `build`, copies the worker and shared modules into `public/vendor/` (git-ignored), and the map points at them
with `setWorkerUrl`.

## Design system

Dark-first, single theme. Tokens live in `src/app/globals.css` under `@theme`: near-black ground, off-white type, one
violet-blue accent (`#8785ff`), hairline borders instead of shadows, film grain over the page. Type: Bricolage Grotesque
(display), Instrument Sans (body), Geist Mono (labels and numbers), all via `next/font`.

The card (`src/components/card/`) is CSS: a brushed-metal bezel from a conic gradient, a 2×2 twill carbon-fibre face from
`public/textures/carbon.svg`, a moving clearcoat gloss and specular highlight driven by pointer position, a gold EMV chip,
and an enamel-pin flag of the country you moved from. Flags are the `country-flag-icons` SVG set copied into `public/flags`.

## Deploy

Vercel: import the repo, set the env vars, point `resident-alien.com` at the project. `vercel.json` schedules the
coach's daily tick. The OG image, sitemap, and
robots are generated by the app.
